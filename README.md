# Falling Hello App

Aplicativo Android nativo em Kotlin com um texto `Hello World` caindo em tela com efeito de física simples.

## Estrutura

- `app/src/main/java/com/example/fallinghello/MainActivity.kt`
- `app/src/main/java/com/example/fallinghello/FallingHelloView.kt`
- `app/src/main/res/layout/activity_main.xml`

## Como abrir no Android Studio

1. Abra a pasta `FallingHelloApp` no Android Studio.
2. Aguarde o Gradle sincronizar.
3. Execute a app em um emulador ou dispositivo Android.

## Observação

Este ambiente atual não possui Android SDK/Gradle configurados, então a geração real do APK precisa ser feita no Android Studio em um ambiente com SDK Android instalado.
